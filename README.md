# Gamage Builders — Static Website

A multi-page static website for **Gamage Builders** (est. 1993), Akuressa, Sri Lanka.

## Pages

| File | Page |
|------|------|
| `index.html` | Home |
| `projects.html` | Projects |
| `services.html` | Services |
| `about.html` | About |
| `contact.html` | Contact Us |

## How to view

1. Open the folder `Gamage Builders` on your computer.
2. Double-click **`index.html`** to open in your browser.

No server is required. For best results when testing forms or maps, you can use a simple local server (optional).

## Your logo

1. Save your company logo image as:
   **`images/Company_Logo.png`**
2. Recommended: PNG with transparent background (remove white backdrop in an editor if needed).
3. If `Company_Logo.png` is missing, the site uses `images/logo.svg` as a fallback.

## Customise before going live

- **Social links:** Edit Facebook, Instagram, and LinkedIn URLs in the footer of each HTML file (search for `facebook.com`).
- **Project photos:** Replace Unsplash placeholder images on `projects.html` and the home page with photos of your real work.
- **Contact form:** Quote requests are sent to **info@gamagebuilders.lk** via [FormSubmit](https://formsubmit.co). On the first submission, check that inbox for a one-time activation link from FormSubmit.
- **Map:** The contact page embeds Google Maps for your Akuressa address; adjust the iframe `src` if needed.
